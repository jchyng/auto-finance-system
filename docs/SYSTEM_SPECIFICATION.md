# 주식 투자 분석 시스템 (1차 MVP) 시스템 정의서
> **System Specification Document (Phase 1 MVP)**
> 기준: 2026-09-20 확정안 (선택지 B 채택)

---

## 1. 프로젝트 개요 및 핵심 원칙

### 1.1 목적
본 시스템은 개인 투자자가 종목을 입력했을 때, 주관적 추천이나 근거 없는 AI 판단을 배제하고 **객관적인 공시/시장 데이터와 검증된 수학적 계산식만을 사용하여 기업의 투자 검토 기초 자료를 자동 생성**하는 시스템이다.

### 1.2 8대 개발 원칙
1. **객관성 (Objectivity)**: 수치로 측정 가능한 객관적 사실만 포함한다.
2. **투자 판단 권유 금지 (No Advice)**: "매수 추천", "매도 추천", "저평가 확정", "좋은 기업" 등의 단정적 표현을 절대 사용하지 않는다.
3. **명확한 근거 (Verifiable Grounds)**: 모든 판정에는 숫자, 과거 5년 평균, 업종 평균 등 명확한 비교 근거가 존재해야 한다.
4. **원본과 계산의 분리 (Data Separation)**: 수집된 원본 데이터(Raw Data)와 계산된 지표(Calculated Metrics)를 엄격히 분리 보관한다.
5. **엔지니어링과 AI의 역할 분리 (Code vs AI)**:
   * **일반 코드 (Python)**: 수집, 정제, 지표 계산, 평균 산출, 상대 비교, 규칙 기반 상태 판정 (100% 담당)
   * **AI (LLM)**: 계산된 결과에 대한 사실 요약 및 초보자를 위한 금융 용어 해설만 담당 (숫자 계산 및 지표 임의 생성 금지)
6. **검증 가능성 (Auditability)**: 분자/분모 값, 적용된 공식, 데이터 기준일(결산기), 데이터 출처를 투명하게 공개한다.
7. **예외 및 결측치 처리 (Graceful Degradation)**: 데이터 부재, 적자 왜곡, 금융업 특성 등으로 판단이 어려운 경우 억지로 값을 넣지 않고 `데이터 부족` 또는 `판단불가`로 명시한다.
8. **단위 독립성 (Modularity)**: 모든 기능 모듈은 단독 실행 및 테스트가 가능해야 하며, 이를 파이프라인으로 연결하여 완성한다.

## 2. 15개 핵심 투자지표 정의 및 계산 공식

> [!NOTE]
> 사용자 합의(선택지 B)에 따라 15개 모든 지표를 산출하며, 정의 편차가 존재하는 3개 지표(FCF, ROIC, EV/EBITDA)는 아래 명시된 **"표준 간이 공식"**을 시스템 표준으로 채택하고 화면에 공식을 명시한다.

### 2.1 성장성 (Growth)
* **매출액 성장률 (YoY)**:
  $$\text{매출액 성장률} = \frac{\text{당기 매출액} - \text{전기 매출액}}{\text{전기 매출액}} \times 100$$
* **영업이익 성장률 (YoY)**:
  $$\text{영업이익 성장률} = \frac{\text{당기 영업이익} - \text{전기 영업이익}}{|\text{전기 영업이익}|} \times 100$$
  * *예외*: 전기 적자 → 당기 흑자(`흑자전환`), 전기 적자 → 당기 적자(`적자지속`), 전기 흑자 → 당기 적자(`적자전환`) 문구 병기.
* **EPS 성장률 (YoY)**:
  $$\text{EPS 성장률} = \frac{\text{당기 수정EPS} - \text{전기 수정EPS}}{|\text{전기 수정EPS}|} \times 100$$
  * *주의*: 액면분할, 유/무상증자를 반영한 수정기본EPS 기준.
* **FCF 성장률 (YoY)**:
  $$\text{FCF 성장률} = \frac{\text{당기 FCF} - \text{전기 FCF}}{|\text{전기 FCF}|} \times 100$$

### 2.2 수익성 (Profitability)
* **영업이익률**:
  $$\text{영업이익률} = \frac{\text{영업이익}}{\text{매출액}} \times 100$$
* **ROE (자기자본이익률)**:
  $$\text{ROE} = \frac{\text{당기순이익 (지배주주순이익)}}{\text{평균 자기자본 (지배주주지분)}} \times 100$$
  * *기준*: 평균 자기자본 = $(\text{기초자본} + \text{기말자본}) / 2$
* **ROA (총자산이익률)**:
  $$\text{ROA} = \frac{\text{당기순이익}}{\text{평균 총자산}} \times 100$$
  * *기준*: 평균 총자산 = $(\text{기초자산} + \text{기말자산}) / 2$
* **ROIC (투하자본이익률 - 표준 간이 공식)**:
  $$\text{ROIC} = \frac{\text{세후영업이익 (NOPAT)}}{\text{투하자본 (IC)}} \times 100$$
  * $\text{NOPAT} = \text{영업이익} \times (1 - \text{법인세 실효세율})$ (실효세율 비정상 시 법정세율 20% 대용)
  * $\text{투하자본(IC)} = \text{순차입금} + \text{자기자본}$ (또는 정제 요약 데이터의 IC 채택)

### 2.3 재무건전성 (Financial Health)
* **부채비율**:
  $$\text{부채비율} = \frac{\text{총부채}}{\text{총자본}} \times 100$$
  * *예외*: 금융업(은행/증권/보험)은 고객 부채 특성상 `판단불가(업종 특성)` 처리.
* **유동비율**:
  $$\text{유동비율} = \frac{\text{유동자산}}{\text{유동부채}} \times 100$$
  * *예외*: 금융업은 유동/비유동 미구분으로 `판단불가(업종 특성)` 처리.
* **이자보상배율**:
  $$\text{이자보상배율} = \frac{\text{영업이익}}{\text{이자비용}}$$
  * *예외*: 무차입 기업(이자비용 = 0)은 `양호(무차입 우량)` 명시.
* **FCF (잉여현금흐름 절대액 - 표준 간이 공식)**:
  $$\text{FCF} = \text{영업활동현금흐름} - (\text{유형자산의 취득} + \text{무형자산의 취득})$$

### 2.4 밸류에이션 (Valuation)
* **PER (주가수익비율)**:
  $$\text{PER} = \frac{\text{현재 주가}}{\text{주당순이익 (EPS)}} = \frac{\text{시가총액}}{\text{지배주주순이익}}$$
  * *예외*: 당기순손실(적자) 시 음수(-)가 되므로 `적자 (N/A)` 처리.
* **PBR (주가순자산비율)**:
  $$\text{PBR} = \frac{\text{현재 주가}}{\text{주당순자산 (BPS)}} = \frac{\text{시가총액}}{\text{지배주주자기자본}}$$
  * *예외*: 완전자본잠식 기업은 `자본잠식 (N/A)` 처리.
* **EV/EBITDA (표준 간이 공식)**:
  $$\text{EV/EBITDA} = \frac{\text{EV (기업가치)}}{\text{EBITDA}}$$
  * $\text{EV} = \text{시가총액} + \text{총차입금} - \text{현금 및 현금성자산}$
  * $\text{EBITDA} = \text{영업이익} + \text{감가상각비(유형자산상각비 + 무형자산상각비)}$
  * *예외*: 금융업종은 차입금 개념이 상이하므로 `판단불가(업종 특성)` 처리.

## 3. 객관적 상태 판정 기준 및 예외 규칙

### 3.1 4단계 상태 정의
* **`양호`**: 객관적 안전 기준을 충족하며, 기업의 과거 추이 및 업종 평균 대비 우수한 상태.
* **`보통`**: 업종 평균 또는 과거 평균 수준에 부합하며 중대한 위험 징후가 없는 상태.
* **`주의`**: 재무적 결손 위험이 있거나, 업종 및 과거 평균 대비 현저히 저조한 상태.
* **`판단불가`**: 결손(적자) 왜곡, 데이터 누락, 금융업 특성상 적용 불가능한 경우.

### 3.2 영역별 판정 로직
1. **재무건전성 (공인 절대 기준 우선 적용)**:
   * **부채비율**: $\le 100\%$ `양호` / $100\% < x \le 200\%$ `보통` / $> 200\%$ `주의` (한국은행/금감원 권고선)
   * **유동비율**: $\ge 150\%$ `양호` / $100\% \le x < 150\%$ `보통` / $< 100\%$ `주의`
   * **이자보상배율**: $\ge 3.0$배 `양호` / $1.0 \le x < 3.0$배 `보통` / $< 1.0$배 `주의(잠재부실)` / 무차입 `양호(무차입 우량)`
   * **FCF 금액**: 최근 3년 연속 흑자(+) `양호` / 당기 흑자(+) `보통` / 당기 적자(-) 또는 2년 연속 적자 `주의`
2. **성장성 및 수익성 (상대 벤치마크 기준)**:
   * `양호`: 현재값 $\ge$ 5년 평균 **AND** 현재값 $\ge$ 업종 평균
   * `주의`: 현재값 $<$ 5년 평균 $\times 0.8$ **AND** 현재값 $<$ 업종 평균 $\times 0.8$
   * `보통`: 위 조건 사이 (개선 중이거나 업종 수준 유지)
   * `판단불가`: 적자로 인한 계산 불가
3. **밸류에이션 (상대 벤치마크 기준)**:
   * `과거 및 업종 대비 낮음`: 현재값 $<$ 5년 평균 **AND** 현재값 $<$ 업종 평균
   * `과거 및 업종 대비 높음`: 현재값 $>$ 5년 평균 **AND** 현재값 $>$ 업종 평균
   * `보통`: 평균치 $\pm 15\%$ 이내
   * `판단불가`: 당기순손실(적자)

## 4. 공인 데이터 소스 구성 전략 (Official & Free Data Sources)
1. **금융감독원 DART Open API (`opendart.fss.or.kr`)**: 법정 공시 사업보고서 5개년 원본 재무제표 수집 (100% 공인 / 무료).
2. **한국거래소(KRX) 공식 데이터 (`pykrx`)**: 상장 종목 정보, 당일 주가, 시가총액, 상장주식수, KRX 업종별 PER/PBR 지표 수집 (100% 공인 / 무료).
3. **오프라인 검증용 실제 공시 Fixture (`data/fixtures/`)**: API Key 발급 전이라도 삼성전자/현대차/신한지주를 즉시 테스트할 수 있도록 실제 DART 공시 원본 샘플 탑재.
4. **로컬 캐시 (JSON / SQLite)**: 동일 종목 재호출 시 API 트래픽 절약 및 속도 향상.
