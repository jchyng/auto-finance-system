# 모듈 3: 재무제표 정제기 (CLI 단독 실행)
모듈 2에서 생성된 JSON(또는 fixture)을 입력으로 받아 표준화된 정제 JSON을 출력합니다.

## 삼성전자 fixture로 정제 테스트
python -m src.normalizers.financial_statement_normalizer `
    --input data/fixtures/005930_samsung_electronics_dart_financials.json `

## 현대자동차 정제 테스트

## 신한지주(금융업) 정제 테스트
python -m src.normalizers.financial_statement_normalizer `
